# 🚀 Название твоего проекта
Телеграм бот 'холодильник'
Следите за статусом и количеством продуктов не находясь дома 
## ✨ Что умеет
- Отправляет напоминания купить продукты которых осталось мало (в 2 часа дня и 6 часов вечера)
- Сам вычисляет сколько продуктов осталось мало (=<3)
- Показывает количество продуктов
- Отображает когда в последний раз статус продуктов обновляли
